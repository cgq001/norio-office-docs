Office Excel 是 Vue 3 在线表格组件，适合预算、台账、业务数据录入和报表编辑。编辑对象是完整工作簿，包含多个工作表及其单元格、样式、表对象和图表等结构。

## 可以完成什么

| 功能 | 使用场景 |
| --- | --- |
| 单元格编辑与格式 | 输入文字、数字、公式，设置数字格式、对齐、边框和颜色 |
| 行列和工作表 | 调整表结构、插入删除、管理多张工作表 |
| 合并、填充与粘贴 | 合并区域、拖拽填充、移动区域、粘贴特殊 |
| 公式与重算 | 通过公式表达计算关系，使用依赖图、重算计划及公式提示 |
| 排序与筛选 | 多条件排序、数值和文本条件筛选、管理筛选状态 |
| 数据验证 | 为数据录入配置校验规则 |
| 命名区域和表对象 | 给业务区域建立稳定语义，管理结构化数据表 |
| 透视结果和图表 | 整理汇总数据，创建和调整可视化对象 |
| 文件与快照 | XLSX 导入导出，JSON 快照保存恢复，纯文本读取 |
| AI 局部修改 | 在授权区域内改值、公式、样式，或操作表、图表等支持的对象 |

## 从一张费用表开始

创建空工作簿，录入“项目、数量、单价、金额”四列。用公式计算金额，给金额列设置数字格式，再按项目筛选。保存完整工作簿快照，或导出 XLSX 交付给其他用户。

当你希望“只给金额列保留两位小数”时，AI 应捕获该区域并提交格式补丁。对跨表操作，Bridge 可以捕获真实工作表 ID 下的目标，无需强行切换用户当前界面。

## 先理解两个数据概念

`v-model` 绑定的是 `OfficeExcelWorkbookSnapshot`，不是二维字符串数组。只保存单元格显示文字会丢失公式、样式、图片和工作表结构。

API 中的坐标规则与具体方法有关。AI 区域例子使用从 1 开始的行列号；协作结构操作使用稳定行列 ID。不要把 A1 地址、数组下标和稳定 ID 混用。

## 能力边界

正式文件以 `.xlsx` 为主。旧版 `.xls`、宏和外部连接不属于无损承诺。颜色筛选目前缺少可靠的导出映射，会产生 `XLSX_FILTER_COLOR_LOSSY` 兼容报告；严格模式会拒绝相关有损导出。

协作需要 Docker 版本及服务端命令通道。没有服务端原子 AI 批次命令时，协作实例拒绝 AI 写入，不会用全量替换冒充原子提交。
