Office PPT 是 Vue 3 演示文稿组件，提供 PPTX 导入、页面编辑、放映、导出和可选持久化。数据以完整 `OfficePptDeck` 交给宿主，页面、对象与文件资源共同组成一份演示文稿。

## 安装与快速接入

在你的 Vue 3.5+ 项目根目录执行：

```bash
npm install @norio-office/office-ppt
```

[安装说明与依赖要求](/ppt/installation/) · [快速开始：引入组件并运行页面](/ppt/quickstart/)

## 可以完成什么

| 功能 | 使用场景 |
| --- | --- |
| 页面管理 | 新建、复制、删除和排序幻灯片 |
| 对象编辑 | 编辑文字、形状、图片、表格和图表等对象，调整页面构图 |
| 对象剪贴板 | 多选对象复制、剪切、粘贴和重复，整批操作进入撤销历史 |
| 演示放映 | 翻页、动画、画笔、激光笔及演讲者备注 |
| 观众窗口 | 使用独立窗口放映，讲者侧保留备注和缩略图 |
| 音视频 | 插入本地媒体或 HTTP(S) 媒体地址，设置开始方式、循环和音量 |
| 原生动画 | 支持部分运动、旋转、缩放、颜色及数值行为；未知效果保留并提示 |
| 文件输出 | PPTX、图片、PDF；矢量 PDF 需要配置转换服务 |
| 保存与恢复 | 自动保存、保存状态、失败重试和崩溃恢复适配器 |

## 一份汇报的使用流程

导入已有 PPTX，修改标题和数据图表，调整页面顺序；在演讲者视图中查看备注，打开观众窗口进行展示。编辑完成后导出 PPTX，或者根据宿主配置输出 PDF。

如果只需要快速打开，可开启 `fastLoad` 跳过内嵌字体的解码与加载。字体原始资源仍会保留，但使用替代字体可能改变换行和排版，因此不能把它视为完全无差异的显示模式。

## PDF 有两种路径

未提供 `pdfRenderer` 时，组件保留离线导出路径，输出以位图外观和检索层为主。宿主提供转换器后可使用矢量 PDF 服务，常规文字、形状和图表保留矢量，原始位图或复杂滤镜不保证矢量化。

已配置转换器但转换失败时，不会悄悄降级成位图。详见 [PPTX 与 PDF 导出](/ppt/files/)。

## 当前边界

> **PPT AI 接入仍在实施和验收中。** 公开 Bridge 与协议已经提供，但不能把命令数量当作全部功能、参数及真实宿主场景已经验收。当前 AI 与协作的组合不支持。

多人协作需要 Docker 版本。媒体播放依赖浏览器编码支持与自动播放策略；观众窗口需要允许弹窗。复杂母版、主题、嵌入字体和跨文稿复制仍需用实际样本验证。
