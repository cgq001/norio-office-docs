Norio Office 提供文档、表格、演示文稿和富文本四类编辑器。你可以把其中一个接入现有 Vue 应用，也可以在同一产品中组合使用。这个网站只介绍功能与接入方法，不运行编辑器演示。

## 先选择你的场景

| 你想做什么 | 推荐编辑器 | 先读这里 |
| --- | --- | --- |
| 编辑合同、报告，处理纸张、分页、页眉页脚 | Word 文档 | [Word 快速开始](/word/quickstart/) |
| 编辑数据表、公式、筛选和图表 | Excel 表格 | [Excel 快速开始](/excel/quickstart/) |
| 编辑幻灯片、播放演示、处理 PPTX | PPT 演示文稿 | [PPT 快速开始](/ppt/quickstart/) |
| 在业务系统里写知识库、笔记、图文内容 | 富文本 | [富文本快速开始](/rich/quickstart/) |

Word 重视页面和办公文件；富文本重视内容块和网页编辑。两者都有文字和表格能力，但数据结构、文件格式和接入接口不同，不能直接互换 `v-model`。

## 用三步完成第一次接入

1. **让编辑器显示出来。** 安装对应 npm 包，引入样式，按快速开始传入初始数据。Word 还必须准备配套字体和运行资源。
2. **做一次保存和恢复。** 修改内容，获取完整结构化数据或导出文件，再重新打开。页面内 `v-model` 更新不等于数据已经写入数据库。
3. **再接业务能力。** 按需要加入权限、文件上传、AI 或协作。上传地址、文档 ID、鉴权和保存接口由宿主应用提供。

> **多人协作需要部署 Docker 版本。** 安装 npm 组件、打开本网站或部署 Cloudflare 静态页面，都不会自动启动协作服务。具体见 [Docker 协作部署](/guide/collaboration/)。

## 阅读路线

- **了解产品：** 先读四个编辑器的“功能概览”和[功能对照](/guide/comparison/)。
- **前端接入：** 先读对应编辑器的“安装”，再按“快速开始”创建页面；教程中也保留安装命令，可直接从头完成接入。
- **AI 接入：** 先理解[原子级修改](/guide/ai/)，再看对应编辑器的 AI 页面。
- **查参数：** 参数、事件、实例方法在各编辑器的参考文档中独立列出，不需要从头通读。
- **部署文档站：** 按 [Cloudflare 部署](/guide/deployment/) 构建并发布静态文件。

## 示例里的几个约定

完整的 Vue 单文件示例包含 `<script setup>` 和 `<template>`。只列出函数或组件标签的示例是局部片段，需要放进已完成接入的页面。`example.com`、`/api/...`、用户 ID 和文档 ID 均为示意值；注释中标出的宿主函数需要你实现。

本文以 2026-10-25 提供的项目源码文档为依据。安装包和本地源码可能处在不同发布阶段，请使用与你所安装版本匹配的类型定义和能力查询结果。
