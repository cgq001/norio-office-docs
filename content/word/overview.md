Office Word 是 Vue 3 文档编辑组件，支持页面排版、段落样式、表格和审阅功能。可导入 DOCX，编辑后导出 DOCX、PDF、SVG 或 PNG。

## 可以完成什么

| 功能 | 在实际工作中怎么用 |
| --- | --- |
| 文字、段落和样式 | 设置字体格式、段落排版、标题和列表，让长文档层次清楚 |
| 表格 | 插入和编辑单元格、调整行列、合并拆分，处理跨页表格 |
| 图片、形状和文本框 | 插入插图，调整大小、位置、层级和基础环绕 |
| 页面与分节 | 设置纸张、页边距和节，编排不同部分的页面 |
| 页眉、页脚与注释 | 加入页码、脚注、尾注，处理正式文书的辅助信息 |
| 审阅与导航 | 搜索替换、字数页数、大纲、标尺、批注和修订处理 |
| 文件交付 | 导入 DOCX，编辑后导出 DOCX 或输出 PDF / 图片 |
| AI 局部修改 | 对授权的文字、结构或格式进行精确修改，走原生命令和撤销历史 |

## 一份合同的接入流程

先准备字体和 Worker/WASM 资源，让页面正确显示；随后导入合同 DOCX，设置需要的交互模式。用户修改条款后，通过 `getDocumentAsync()` 取得包含已接受输入的完整数据，或调用导出方法生成 DOCX Blob，再交给你的保存接口。

如果用户只想润色某一句，应冻结这一句并通过 AI Bridge 修改，不能用模型生成的整篇文档覆盖已有合同。

## 三种模式

- `edit`：显示编辑工具，允许修改，仍受文档权限约束。
- `preview`：用于阅读，可选择和复制，隐藏编辑工具。
- `disabled`：用于禁止交互修改和复制的展示；仍可滚动查看。

模式不是后端鉴权。宿主仍可按公开接口加载、读取和导出，具体操作也受授权限制。

## 接入前要知道

**字体是必需资源。** 当前组件要求通过 `fontUrls` 配置四个配套字体文件，不能直接替换为任意字体。不同源字体的回退可能影响字宽、换行和分页。

**功能有明确边界。** VBA 宏执行、OLE 激活、完整公式编辑和任意 Word 字段系统不在完整支持范围。已有图表的源数据保留，不代表提供正式 AI 图表创建和编辑能力。

**协作需要 Docker 版本。** 通过 `collaborationProvider` 对接实际服务，不能仅靠前端组件完成多人协作。
